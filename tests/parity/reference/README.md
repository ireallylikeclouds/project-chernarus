# Reference traces

Measurements captured in the reference game, one directory per scenario id:
`<scenario id>/<run>.csv` (format: `crates/parity/src/trace.rs`).

These are PROJECT-CREATED observation data: positions and timings the project
measured, not files copied from the game. Each file's `#` metadata records the
game version, world, unit class and run id reported by the capture script.

None exist yet. To add some, follow [tools/capture/README.md](../../../tools/capture/README.md).
